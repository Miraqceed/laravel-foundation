# laravel-foundation

どの Laravel のアプリにも要る部品を1つにまとめたパッケージです。Laravel 12〜13、PHP 8.3 以上に対応します。Redis や常駐のプロセスには頼らず、`database` のドライバーで動きます。入れただけではアプリの挙動は変わりません（部品は既定で無効です）。

## 部品（準備中）

- テストの守り（開発用 DB に向けたテストを起動前に止める）：準備中
- CSV の書き出し：準備中
- ログインのロック：準備中
- CSP・セキュリティヘッダー：準備中
- 定期の処理の見張りと知らせ：準備中
